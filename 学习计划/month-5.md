## 第 4 周 —— 首个完整项目落地 ⭐⭐

> 本周把前几周所学串成一个可展示的项目,这是简历最核心的一块。

**目标项目:** 在公开数据集(MovieLens 或 Criteo)上,搭一个 **"召回 + 排序" 完整 pipeline**。

**工作日(每天 2h,全部投入项目):**
- [ ] 周一:数据准备与特征工程(用户/物品/上下文特征、样本构造、正负采样)
- [ ] 周二:**召回层**——实现双塔模型,产出候选集(+ Faiss 检索)
- [ ] 周三:**排序层**——用 DeepFM 或 DIN 对候选集精排
- [ ] 周四:**评估**——计算 Recall@K、NDCG@K、AUC,对比不同模型
- [ ] 周五:整理代码结构,写清晰的 README(动机、方案、指标、结论)

**周末:**
- [ ] 周六:补充实验(调参、消融),把指标提升过程记录下来
- [ ] 周日:**本月复盘** + 项目上传到 GitHub(干净的 README + 指标)+ 刷 2–3 题,冲到 ~150 题

**本周产出:** 一个可展示的端到端推荐项目(GitHub);累计 ~150 题。

## 本月执行要点

1. **DIN 和双塔是两大高频考点**,一个代表排序侧兴趣建模,一个代表召回侧,务必都能讲能写。
2. **全链路架构图**要能默画并逐环节讲解——这是区分"只会调模型"和"懂系统"的关键。
3. **项目要能讲出"为什么这么做 + 指标提升多少"**,而不是堆模型。面试官最看重这个。
4. **前沿(LLM/生成式推荐)**了解即可,但能聊两句是很强的加分项。
5. 做完项目即可**开始投递简历**,不用等第 6 个月学完。
