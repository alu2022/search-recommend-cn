# 第 1 个月 —— 打地基

**本月总目标:** Python 熟练(含 NumPy/Pandas)、SQL 会写、数学补漏、LeetCode 起步累计 ~30 题。

> 时间安排:工作日每天 2h(拆成 1h 学 + 1h 刷题),周末每天约 6h。

---

## 第 1 周 —— Python 基础补强 + 刷题起步

**工作日(1h 学 + 1h 刷题):**
- [ ] 周一:变量/数据类型/字符串操作 + LeetCode 1 题(数组类,如两数之和)
- [ ] 周二:列表/字典/集合/元组的用法和区别 + 刷 1 题(数组/哈希表)
- [ ] 周三:条件/循环/推导式(list/dict comprehension)+ 刷 1 题
- [ ] 周四:函数、参数、作用域、lambda + 刷 1 题(字符串)
- [ ] 周五:异常处理、文件读写 + 刷 1 题

**周末(每天约 6h):**
- [ ] 周六:面向对象(类、继承、`__init__`、魔术方法)+ 手写 2–3 个小类练习
- [ ] 周日:综合练习(写一个小脚本,比如读 CSV 做统计)+ 刷 2 题 + 回顾本周

**本周产出:** 能独立写带类的 Python 脚本;LeetCode 累计 ~7 题。
**资料:** 廖雪峰 Python 教程 /《Python 编程:从入门到实践》。

## 本月执行要点

1. **刷题贯穿全月**:工作日的第 2 个小时固定给 LeetCode,先按标签刷(数组→哈希→双指针→字符串→链表),用 Python 写。
2. **数学"理解即可"**:这个月不追求会证明,能看懂几何/直观含义就行。
3. **代码都要亲手敲**:尤其 Pandas 和 SQL,看会 ≠ 写得出。
4. **周末整块时间做综合练习**,工作日碎片时间做"看 + 刷"。
5. **每周日固定回顾**,不熟的记下来,别积压。
