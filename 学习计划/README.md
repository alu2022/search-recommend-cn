## 一、市场判断(为什么值得投入)

推荐系统是机器学习里"最能直接变现"的方向之一,长期缺人、薪资中上。

**为什么长期有需求:**
- 直接和钱挂钩。电商、短视频、内容、广告、外卖、音乐——只要有"信息流/猜你喜欢"就离不开推荐,优化 1% 点击率可能就是千万级营收,公司愿意砸钱砸人。
- 它是算法岗里**最工程化**的方向,不容易被大模型一锅端(要处理海量实时数据、低延迟在线服务、AB 实验)。

**要提前知道的现实:**
- **门槛在抬高**:早年会调 DeepFM 就能进,现在要求懂全链路(召回→粗排→精排→重排)+ 大数据工程 + 真实业务落地。
- **头部集中**:好岗位主要在字节、阿里、腾讯、快手、美团、小红书、拼多多等有大规模推荐场景的公司。
- **大模型是双刃剑**:纯调参价值在下降;懂业务 + 懂系统 + 跟得上前沿(LLM/生成式推荐)的人更贵。

**一句话结论**:天花板高、值得投入。最优画像 = **扎实 coding + 懂全链路 + 一个完整端到端项目 + 跟得上大模型前沿**。

## 三、贯穿全程的两条并行线(不单独算时间)

1. **LeetCode**:从第 1 个月就开始,工作日第 2 个小时固定刷题,目标累计 **200+ 题**。国内笔试硬门槛。
   - 刷题顺序建议:数组 → 哈希表 → 双指针 → 字符串 → 链表 → 栈/队列 → 二叉树 → 动态规划 → 回溯。
   - 用 Python 写,重在掌握套路而非题量。
2. **积累"八股"笔记**:从第 4 个月起,把每个推荐模型的原理、适用场景、优缺点整理成自己的问答库(面试高频)。

## 四、核心学习资料清单

**书籍:**
- 王喆《深度学习推荐系统》—— 国内该岗位的"面试圣经",第 4–5 月精读。
- 项亮《推荐系统实践》—— 经典入门。
- 李航《统计学习方法》—— ML 公式查漏补缺。

**课程 / 在线资料:**
- 吴恩达机器学习课(Coursera / B 站) —— ML 打底。
- 《动手学深度学习》(<https://d2l.ai>,免费) —— DL 主线,边看边敲。
- 3Blue1Brown《线性代数的本质》《微积分的本质》(B 站) —— 数学直观。

**开源仓库(实践参考):**
- [RecBole](https://github.com/RUCAIBox/RecBole) —— 推荐算法集合,学召回/排序模型。
- [DeepCTR](https://github.com/shenweichen/DeepCTR) —— CTR/排序模型实现参考。
- [Microsoft Recommenders](https://github.com/microsoft/recommenders) —— 召回+排序 pipeline 与 notebook 案例。
- [Faiss](https://github.com/facebookresearch/faiss) —— 向量召回。

**常用公开数据集(做项目用):**
- MovieLens(入门首选)、Criteo(CTR 点击数据)、Amazon Reviews。

## 五、执行铁律

1. **能跑通 + 能讲清楚 + 有指标**,远比"看了多少课"重要。推荐系统极度重实践。
2. **别陷在"无限看视频"的舒适区**,每学一块必须动手写代码。
3. **周末整块时间**留给需要连续投入的事(复现模型、做项目);**工作日 2 小时**做碎片化任务(刷题、看课、读文档)。
4. **每周日固定复盘**,把不熟的记下来,别积压。
5. **不用等全部学完再投简历**:做完第 5 个月的第一个项目就可以边投边补。
